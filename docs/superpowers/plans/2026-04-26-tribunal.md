# Tribunal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a verifiable, multi-judge AI court for autonomous agents — agents file disputes over Gensyn AXL, lawyer agents argue, a panel of judge iNFTs (ERC-7857) rule, escrow is released by KeeperHub, every event is anchored on 0G Chain. Generic dispute resolution with escrow as the launch use case. Submission to ETHGlobal Open Agents in 10 days.

**Architecture:** Monorepo with four workspaces: `contracts` (Hardhat + Solidity for case state machine, escrow adapter, ERC-8004 registry, ERC-7857 judge iNFTs, verdict log), `agents` (TypeScript runtime for judge / lawyer / clerk roles using AXL transport, ENS identity, 0G Storage, LLM via Anthropic SDK), `web` (Next.js UI for filing disputes, watching live trials, viewing verdicts), `keeper` (KeeperHub workflow definitions for ruling execution and procedural deadlines).

**Tech Stack:** TypeScript, Solidity, Hardhat, ethers.js v6, `@0glabs/0g-ts-sdk`, Anthropic SDK (`@anthropic-ai/sdk`), Gensyn AXL (localhost HTTP API on `:9002`), ENS (`@ensdomains/ensjs` + ENSIP-25 text records), Next.js 14 (App Router), WebSockets, KeeperHub, Vitest (agent tests), Hardhat (contract tests), 0G Chain testnet.

- [ ] **Step 4: Implement `axl.ts`**

```ts
// agents/src/transport/axl.ts
export interface AxlClient {
  send(toPeerId: string, payload: unknown): Promise<void>;
  peerId(): Promise<string>;
}

export interface CreateAxlClientOptions {
  baseUrl: string;
  fetchImpl?: typeof fetch;
}

export function createAxlClient(opts: CreateAxlClientOptions): AxlClient {
  const f = opts.fetchImpl ?? fetch;
  return {
    async send(toPeerId, payload) {
      const res = await f(`${opts.baseUrl}/send`, {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({ to: toPeerId, data: JSON.stringify(payload) }),
      });
      if (!res.ok) {
        throw new Error(`AXL /send failed: HTTP ${res.status} ${await res.text()}`);
      }
    },
    async peerId() {
      const res = await f(`${opts.baseUrl}/id`);
      if (!res.ok) throw new Error(`AXL /id failed: HTTP ${res.status}`);
      const body = (await res.json()) as { id: string };
      return body.id;
    },
  };
}
```

```ts
// add to agents/src/transport/axl.ts
export interface IncomingEnvelope {
  from: string;          // peer id
  payload: unknown;      // JSON-parsed
}

export function subscribe(
  client: AxlClient,
  baseUrl: string,
  onMessage: (env: IncomingEnvelope) => void,
  fetchImpl: typeof fetch = fetch,
): () => void {
  let stopped = false;
  (async () => {
    while (!stopped) {
      try {
        const res = await fetchImpl(`${baseUrl}/recv?wait=15`); // long-poll
        if (res.ok) {
          const list = (await res.json()) as { from: string; data: string }[];
          for (const m of list) {
            try {
              onMessage({ from: m.from, payload: JSON.parse(m.data) });
            } catch (e) {
              console.warn("axl: bad payload", e);
            }
          }
        }
      } catch (e) {
        await new Promise((r) => setTimeout(r, 500));
      }
    }
  })();
  return () => { stopped = true; };
}
```

```ts
// agents/src/llm/client.ts
import Anthropic from "@anthropic-ai/sdk";

export interface LlmMessage { role: "user" | "assistant"; content: string }
export interface CompleteArgs {
  system: string;
  messages: LlmMessage[];
  maxTokens?: number;
}
export interface CompleteResult { text: string; inputTokens: number; outputTokens: number }
export interface Llm { complete(args: CompleteArgs): Promise<CompleteResult> }

export interface CreateLlmOpts {
  sdk?: Anthropic;
  apiKey?: string;
  model: string;
}

export function createLlm(opts: CreateLlmOpts): Llm {
  const sdk = opts.sdk ?? new Anthropic({ apiKey: opts.apiKey ?? process.env.ANTHROPIC_API_KEY! });
  return {
    async complete(args) {
      const resp = await sdk.messages.create({
        model: opts.model,
        max_tokens: args.maxTokens ?? 2048,
        system: args.system,
        messages: args.messages,
      });
      const block = resp.content.find((c: any) => c.type === "text") as any;
      return {
        text: block?.text ?? "",
        inputTokens: resp.usage.input_tokens,
        outputTokens: resp.usage.output_tokens,
      };
    },
  };
}
```

```ts
export interface UploadResult { rootHash: `0x${string}`; txHash: `0x${string}` }

export interface StorageClient {
  upload(bytes: Uint8Array): Promise<UploadResult>;
  download(rootHash: `0x${string}`): Promise<Uint8Array>;
```

```ts
// agents/src/identity/ens.ts
export type AgentRole = "judge" | "lawyer" | "litigant" | "clerk";

export interface ENSIP25KeyArgs {
  registryInteropAddress: string;     // ERC-7930 form, e.g. "eip155:80087:0x..."
  agentId: string;                    // numeric or string id within the registry
}
export function ensip25TextRecordKey(a: ENSIP25KeyArgs): string {
  return `verified-agent:${a.registryInteropAddress}:${a.agentId}`;
}

export interface AgentRecordArgs extends ENSIP25KeyArgs {
  role: AgentRole;
  axlPeerId: string;
  pubKey: string;
  credentials?: string[];
}

export function agentEnsRecord(a: AgentRecordArgs): Record<string, string> {
  return {
    [ensip25TextRecordKey(a)]: "1",
    "agent.role": a.role,
    "agent.axl-peer-id": a.axlPeerId,
    "agent.pubkey": a.pubKey,
    ...(a.credentials?.length ? { "agent.credentials": a.credentials.join(",") } : {}),
  };
}
```

```solidity
// contracts/src/EscrowAdapter.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import { IERC20 } from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import { SafeERC20 } from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";

contract EscrowAdapter {
    using SafeERC20 for IERC20;

    enum Status { None, Open, Disputed, Released }

    struct Escrow {
        address depositor;
        address counterparty;
        IERC20  token;
        uint256 amount;
        Status  status;
    }

    address public immutable tribunal;
    uint256 public nextId = 1;
    mapping(uint256 => Escrow) public escrows;

    event EscrowOpened(uint256 indexed id, address indexed depositor, address indexed counterparty, address token, uint256 amount);
    event EscrowDisputed(uint256 indexed id);
    event EscrowReleased(uint256 indexed id, address indexed to);

    constructor(address tribunal_) { tribunal = tribunal_; }

    function open(address counterparty, address token, uint256 amount) external returns (uint256 id) {
        require(amount > 0, "zero");
        id = nextId++;
        escrows[id] = Escrow(msg.sender, counterparty, IERC20(token), amount, Status.Open);
        IERC20(token).safeTransferFrom(msg.sender, address(this), amount);
        emit EscrowOpened(id, msg.sender, counterparty, token, amount);
    }

    function flagDisputed(uint256 id) external {
        Escrow storage e = escrows[id];
        require(msg.sender == tribunal, "only tribunal");
        require(e.status == Status.Open, "bad state");
        e.status = Status.Disputed;
        emit EscrowDisputed(id);
    }

    function release(uint256 id, address to) external {
        require(msg.sender == tribunal, "only tribunal");
        Escrow storage e = escrows[id];
        require(e.status == Status.Open || e.status == Status.Disputed, "bad state");
        require(to == e.depositor || to == e.counterparty, "bad recipient");
        e.status = Status.Released;
        e.token.safeTransfer(to, e.amount);
        emit EscrowReleased(id, to);
    }
}
```

```solidity
// contracts/src/TribunalCore.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import { ITribunal } from "./interfaces/ITribunal.sol";

interface IRegistry {
    function agents(uint256) external view returns (address owner, string memory ens, string memory role, bool active);
}

interface IEscrow {
    function flagDisputed(uint256 id) external;
}

contract TribunalCore is ITribunal {
    IRegistry public immutable registry;
    address public immutable runner;       // operator that anchors events; restricted in MVP

    struct Case {
        CaseStatus status;
        uint256 accuserId;
        uint256 defendantId;
        address escrowAdapter;
        uint256 escrowId;
        uint256[] judges;
        uint256 threshold;
        uint256 yes;        // votes for accuser-prevailing
        uint256 no;
        uint256 nextSeq;
        bool    prevailingIsAccuser;
    }

    uint256 public nextCaseId = 1;
    mapping(uint256 => Case) private cases;
    mapping(uint256 => mapping(uint256 => bool)) public hasRuled; // caseId => agentId => bool

    constructor(address registry_) {
        registry = IRegistry(registry_);
        runner = msg.sender;
    }

    modifier onlyRunner() { require(msg.sender == runner, "not runner"); _; }

    function fileCase(
        uint256 accuserAgentId,
        uint256 defendantAgentId,
        address escrowAdapter,
        uint256 escrowId,
        string calldata accusationCid
    ) external override returns (uint256 id) {
        (address aOwner,,,) = registry.agents(accuserAgentId);
        require(aOwner == msg.sender, "not accuser");
        id = nextCaseId++;
        Case storage c = cases[id];
        c.status = CaseStatus.Filed;
        c.accuserId = accuserAgentId;
        c.defendantId = defendantAgentId;
        c.escrowAdapter = escrowAdapter;
        c.escrowId = escrowId;
        if (escrowAdapter != address(0)) IEscrow(escrowAdapter).flagDisputed(escrowId);
        emit CaseFiled(id, accuserAgentId, defendantAgentId, escrowAdapter, escrowId, accusationCid);
    }

    function acceptCase(uint256 id, uint256[] calldata judgeIds, uint256 threshold) external onlyRunner {
        Case storage c = cases[id];
        require(c.status == CaseStatus.Filed, "bad state");
        require(judgeIds.length > 0 && threshold > 0 && threshold <= judgeIds.length, "bad panel");
        c.judges = judgeIds;
        c.threshold = threshold;
        c.status = CaseStatus.Arguments;
        emit CaseAccepted(id, judgeIds);
    }

    function recordEvent(uint256 id, bytes32 contentHash) external onlyRunner {
        Case storage c = cases[id];
        require(uint8(c.status) >= uint8(CaseStatus.Filed) && c.status != CaseStatus.Settled, "bad state");
        c.nextSeq += 1;
        emit CaseEvent(id, c.nextSeq, msg.sender, contentHash);
    }

    function submitRuling(uint256 id, bool prevailingIsAccuser, bytes32 opinionHash) external {
        Case storage c = cases[id];
        require(c.status == CaseStatus.Arguments || c.status == CaseStatus.Deliberation, "bad state");

        // confirm sender owns one of the assigned judge ids
        uint256 judgeId = 0;
        for (uint256 i = 0; i < c.judges.length; i++) {
            (address jOwner,,,) = registry.agents(c.judges[i]);
            if (jOwner == msg.sender) { judgeId = c.judges[i]; break; }
        }
        require(judgeId != 0, "not a judge for this case");
        require(!hasRuled[id][judgeId], "double vote");
        hasRuled[id][judgeId] = true;

        if (prevailingIsAccuser) c.yes += 1; else c.no += 1;
        emit RulingSubmitted(id, judgeId, prevailingIsAccuser, opinionHash);

        if (c.yes >= c.threshold || c.no >= c.threshold) {
            c.status = CaseStatus.Ruled;
            c.prevailingIsAccuser = c.yes >= c.threshold;
            emit CaseRuled(id, c.prevailingIsAccuser);
        }
    }

    function caseStatus(uint256 id) external view returns (CaseStatus) { return cases[id].status; }
    function caseJudges(uint256 id) external view returns (uint256[] memory) { return cases[id].judges; }
    function caseThreshold(uint256 id) external view returns (uint256) { return cases[id].threshold; }
    function casePrevailing(uint256 id) external view returns (bool) { return cases[id].prevailingIsAccuser; }
    function caseAccuser(uint256 id) external view returns (uint256) { return cases[id].accuserId; }
    function caseDefendant(uint256 id) external view returns (uint256) { return cases[id].defendantId; }
    function caseEscrow(uint256 id) external view returns (address, uint256) { return (cases[id].escrowAdapter, cases[id].escrowId); }
}
```

```solidity
        _uri[id]  = uri;

    function rulingHistory(uint256 id) external view returns (bytes32[] memory) { return _history[id]; }
```

```ts
import { keccak256, toUtf8Bytes } from "ethers";

export type EventKind = "filing" | "acceptance" | "argument" | "evidence" | "deliberation" | "ruling";
export interface RawEvent { kind: EventKind; from: string; body: string; meta?: Record<string, unknown> }
export interface Event extends RawEvent { caseId: string; seq: number; contentHash: `0x${string}`; timestamp: number }

export class Transcript {
  private events: Event[] = [];
  constructor(public readonly caseId: string) {}
  append(e: RawEvent): Event {
    const seq = this.events.length + 1;
    const timestamp = Date.now();
    const payload = JSON.stringify({ caseId: this.caseId, seq, ...e });
    const contentHash = keccak256(toUtf8Bytes(payload)) as `0x${string}`;
    const stored: Event = { ...e, caseId: this.caseId, seq, contentHash, timestamp };
    this.events.push(stored);
    return stored;
  }
  list(): readonly Event[] { return this.events; }
  size(): number { return this.events.length; }
}
```

```ts
// agents/src/case/state-machine.ts
export enum CaseStatus { Filed = 1, Accepted = 2, Arguments = 3, Deliberation = 4, Ruled = 5, Settled = 6 }

export class CaseSM {
  status: CaseStatus = CaseStatus.Filed;
  judges: string[] = [];
  prevailingIsAccuser?: boolean;
  accept(judges: string[]) { this.assert(CaseStatus.Filed); this.judges = judges; this.status = CaseStatus.Accepted; }
  openArguments() { this.assert(CaseStatus.Accepted); this.status = CaseStatus.Arguments; }
  closeArguments() { this.assert(CaseStatus.Arguments); this.status = CaseStatus.Deliberation; }
  rule(prevailingIsAccuser: boolean) {
    this.assert(CaseStatus.Deliberation, CaseStatus.Arguments);
    this.prevailingIsAccuser = prevailingIsAccuser;
    this.status = CaseStatus.Ruled;
  }
  settle() { this.assert(CaseStatus.Ruled); this.status = CaseStatus.Settled; }
  private assert(...allowed: CaseStatus[]) {
    if (!allowed.includes(this.status)) {
      throw new Error(`illegal transition from ${CaseStatus[this.status]}`);
    }
  }
}
```

```ts
import { Transcript, RawEvent, Event } from "../case/transcript.js";
import type { TribunalClient } from "../chain/tribunal-client.js";
import type { StorageClient } from "../storage/og-storage.js";

export interface ClerkDeps {
  caseId: bigint;
  storage: StorageClient;
  tribunal: TribunalClient;
  forward: (event: Event) => Promise<void>;
  transcript?: Transcript;
}

export interface Clerk {
  handleIncoming(env: { from: string; payload: unknown }): Promise<Event>;
  transcript(): readonly Event[];
}

export function createClerk(deps: ClerkDeps): Clerk {
  const transcript = deps.transcript ?? new Transcript(String(deps.caseId));
  return {
    async handleIncoming(env) {
      const raw = env.payload as RawEvent;
      const ev = transcript.append(raw);
      const blob = new TextEncoder().encode(JSON.stringify(ev));
      await deps.storage.upload(blob);
      await deps.tribunal.anchorEvent(deps.caseId, ev.contentHash);
      await deps.forward(ev);
      return ev;
    },
    transcript() { return transcript.list(); },
  };
}
```

```ts
// web/app/api/stream/[caseId]/route.ts
import { NextRequest } from "next/server";

export const runtime = "nodejs";
export async function GET(req: NextRequest, ctx: { params: { caseId: string } }) {
  const stream = new ReadableStream({
    async start(controller) {
      const encoder = new TextEncoder();
      let stopped = false;
      req.signal.addEventListener("abort", () => { stopped = true; });
      while (!stopped) {
        try {
          const r = await fetch(`http://localhost:9002/recv?wait=15`);
          if (r.ok) {
            const list = (await r.json()) as { from: string; data: string }[];
            for (const m of list) {
              const ev = JSON.parse(m.data);
              if (ev.meta?.caseId === ctx.params.caseId) {
                controller.enqueue(encoder.encode(`data: ${JSON.stringify(ev)}\n\n`));
              }
            }
          }
        } catch (e) { await new Promise((res) => setTimeout(res, 500)); }
      }
      controller.close();
    },
  });
  return new Response(stream, { headers: { "content-type": "text/event-stream" } });
}
```

```markdown
# Tribunal — A verifiable AI court for autonomous agents

When two AI agents transact and disagree, there is no neutral, programmatic forum for resolution. Tribunal provides one: a multi-judge, fully on-chain dispute resolution layer where judges are ERC-7857 iNFTs, lawyers argue over Gensyn AXL, identity is ENS, every event is content-addressed on 0G Storage and anchored on 0G Chain, and rulings are executed by KeeperHub.

## Architecture
See `docs/architecture.md`.

## Deployed addresses (0G testnet)
See `docs/deployment.md`.

## Quickstart
1. `cp .env.example .env` and fill secrets
2. `npm install`
3. `cd contracts && npm run deploy:0g && npm run seed:judges`
4. Start AXL nodes (5 of them; see `scripts/axl-up.sh`)
5. `cd web && npm run dev` and open `localhost:3000`
6. `cd agents && npm run runner` to drive the demo case

## Demo
Watch the demo at <video link>.

## Prize tracks
- 0G Track B (iNFTs): see `contracts/src/JudgeINFT.sol`
- Gensyn AXL: see `agents/src/transport/axl.ts`
- ENS Track A + B: see `agents/src/identity/ens.ts` and `scripts/publish-ens-records.ts`
- KeeperHub: see `keeper/workflows/`
```

```bash
# Tribunal Architecture

## Layers
1. Identity — ENS + ERC-8004 + ENSIP-25
2. Persona — 0G iNFT (ERC-7857)
3. Transport — Gensyn AXL
4. Verifiable record — 0G Storage + Chain
5. Judge consensus — TribunalCore on-chain
6. Execution — KeeperHub
7. Smart contracts — 0G Chain
8. UI — Next.js

## Sequence (single case)

```
[UI] -- file dispute --> [TribunalCore]
                          \--- flagDisputed -> [EscrowAdapter]
[TribunalCore] -- assigns judges --> [Clerk over AXL]
[Lawyer A] <--AXL--> [Clerk] <--AXL--> [Lawyer B]
                            \-- upload events to 0G Storage
                            \-- anchor hashes to TribunalCore
[Judge] <--AXL--> [Clerk]
[Judge] -- submitRuling --> [TribunalCore]
[TribunalCore] -- post --> [VerdictLog]
[KeeperHub] -- listens --> release escrow + notify
```
EOF
```
